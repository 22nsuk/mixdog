# Mixdog 업데이트 안내 (검토용 초안)

테마와 사진 스킨, 대표 봇 오버레이, 대화 중 워크플로우·위임 방식 전환을 추가하고, Windows 코드 서명과 함께 압축·승인·첨부 문제를 크게 정리했습니다.

### 새로운 기능

- **테마** — 설정 → 테마에서 시스템·다크·화이트, 사진 스킨 4종이나 내 사진, 글꼴과 글자 크기를 한 화면에서 고를 수 있도록 추가했습니다.
- **대표 봇 오버레이** — PC 앱에서 대표 봇이 입력창 위에 앉아 답을 말풍선으로 보여 주고, 클릭하면 바로 메시지를 보낼 수 있도록 추가했습니다. 설정 → 봇에서 고를 수 있습니다.
- **대체 모델** — Lead, 대표 봇, 봇 프로필에도 대체 모델을 지정해 사용 한도에 걸리면 다음 모델로 넘어가도록 추가했습니다.
- **워크플로우·위임 방식 전환** — 대화 중에 모델 메뉴에서 워크플로우와 위임 방식을 바꾸면 다음 턴부터 그 대화에만 적용되도록 추가했습니다.
- **스마트 압축** — 설정 → 컨텍스트 → "압축 요약 모델"에서 스마트·Maintainer·대화 모델을 고를 수 있도록 추가했습니다. 기본은 스마트입니다.
- **자동 추론 기준 강도** — 설정 → 일반에서 Auto가 기준으로 삼을 추론 강도를 고를 수 있도록 추가했습니다.
- **이미지 생성** — 스튜디오에서 OpenRouter·NanoGPT 이미지 모델로 그림을 만들 수 있도록 추가했습니다.
- **사이드 패널 위치** — 설정 → 일반에서 사이드 패널을 오른쪽·아래·자동으로 고를 수 있도록 추가했습니다.
- **봇 목록 정리** — 봇을 끌어서 순서를 바꾸고, `…` 메뉴에서 대표 봇·봇·대화방·에이전트를 보이거나 숨기고 "정렬 순서"를 정하며, 실행 중인 작업을 한곳에서 보도록 추가했습니다.

### 변경 사항

- Windows 설치 파일과 앱에 코드 서명을 적용했습니다. Windows 보안 경고와 백신 오탐이 줄어듭니다.
- 브라우저 사용 승인을 OS 창 대신 대화 안 승인 카드로 바꾸고, 파일 업로드도 묻도록 변경했습니다.
- 승인 카드가 요청한 봇과 질문 한 줄을 보여 주고, 거절은 한 번 클릭으로 끝나며, 답할 때까지 저절로 거절되지 않도록 변경했습니다.
- 하위 에이전트의 승인 요청을 최상위 대화에도 띄우고 "세션 열기"로 바로 갈 수 있도록 변경했습니다.
- 봇 프로필에서 "항상 허용"한 항목을 보고 하나씩 "다시 묻기"로 되돌릴 수 있도록 변경했습니다.
- 예약·웹훅은 저장할 때 한 번 승인하면 실행 중에 다시 묻지 않도록 변경했습니다. 결제와 영구 삭제는 실행 중에 하지 않습니다.
- 연결한 휴대폰에서는 봇 권한과 커넥터를 좁힐 수만 있고 넓힐 수는 없도록 변경했습니다.
- 끈 봇이 봇 화면에 "꺼짐"으로 남아 다시 켤 수 있고, 사이드바에서는 따로 숨길 수 있도록 변경했습니다 (#153).
- 하위 에이전트를 화살표 대신 얼굴 클릭이나 우클릭의 "하위 에이전트 보기"로 펼치도록 변경했습니다.
- 모델 선택의 "자동 추론 조절" 스위치를 없애고, 추론 강도 목록 맨 위에 Auto를 두도록 변경했습니다.
- 모델 선택 창이 줄 바로 아래에 열리고, 커스텀 프로바이더는 설정한 이름으로 보이도록 변경했습니다.
- 대화방에서 봇들이 매번 서로 맞장구치지 않고 자연스럽게 말하도록 조정했습니다. Maintainer 모델이 없으면 부른 봇이 한 번씩 답합니다.
- 봇끼리 보낸 메시지에 보낸 봇과 받는 봇을 표시하고, 봇끼리 연달아 주고받는 것은 3번까지로 제한했습니다.
- 작업 끝 카드에는 답에 링크했거나 사이드 패널로 연 파일만 썸네일로 보이도록 변경했습니다.
- 스크롤하는 동안에는 화면이 저절로 움직이지 않고, 맨 아래에 닿으면 다시 새 답을 따라가며, 한꺼번에 온 긴 답은 첫 줄부터 보이도록 변경했습니다.
- 느린 MCP 서버가 있어도 첫 답을 3초 넘게 기다리지 않고, 늦게 연결된 도구는 다음 턴부터 쓰도록 변경했습니다.
- 유휴 세션 자동 정리에 "무제한"을 추가했습니다.
- 에이전트 창의 누적 토큰·비용 줄이 처음부터 자리를 잡아 값이 들어와도 화면이 밀리지 않도록 조정했습니다.
- AI가 설정 도구로 스킬을 만들거나 고칠 때 발동 문구(`when_to_use`)도 정할 수 있도록 안내를 조정했습니다.

### 버그 수정

- 큰 이미지나 PDF를 보낸 Anthropic 대화가 "attachmentReference: Extra inputs are not permitted" 오류로 계속 실패하던 문제를 수정했습니다.
- PDF를 여러 개 첨부하면 컨텍스트 초과로 대화가 막히던 문제를 수정했습니다. 큰 첨부는 이 PC에 두고 필요한 부분만 읽습니다 (#150).
- Word·Excel·브라우저에서 복사한 서식 있는 텍스트가 이미지로 첨부되던 문제를 수정했습니다 (#135).
- 보내지 않은 첨부 파일이 다른 세션에 다녀오면 사라지던 문제를 수정했습니다 (#139).
- 새 작업을 열면 Lead의 모델과 추론 강도가 계속 바뀌던 문제를 수정했습니다 (#149).
- Claude Opus 5.5가 긴 작업 끝에 한국어 대신 영어로 답하던 문제를 수정했습니다. Lead와 봇의 최종 답은 한국어로 나옵니다.
- 강제 종료 뒤 설정·계정 파일이 깨져 로그인과 설정이 사라질 수 있던 문제를 수정했습니다. 이제 마지막 정상 사본으로 복구합니다 (#151).
- 네이버 MYBOX 같은 동기화 폴더에서 파일 만들기·고치기가 EPERM 오류로 실패하던 문제를 수정했습니다 (#138).
- OpenCode Go로 로그인해도 모델 목록이 비어 보이던 문제를 수정했습니다 (#141).
- 코드 정리 엔진 설치가 중단되면 멈춘 채 다시 설치할 수 없던 문제를 수정했습니다. 이제 실패를 알리고 엔진별로 다시 설치할 수 있습니다 (#152).
- 모델 목록이 느린 커스텀 프로바이더를 저장하면 시간 초과로 실패하던 문제를 수정했습니다.
- 새 작업을 시작하면 빈 화면으로 돌아가던 문제를 수정했습니다.
- 앱이나 백그라운드 서비스를 다시 시작하면 끝난 하위 에이전트 목록이 사라지던 문제를 수정했습니다.
- 대표 봇이 맡긴 작업에서 하위 에이전트가 끝나기 전에 중간 답을 결과로 보고하던 문제를 수정했습니다.
- 승인을 기다리는 동안 작업이 멈춘 것으로 표시되거나 시간 초과로 끊기던 문제를 수정했습니다.
- 하위 에이전트가 메인 대화의 컨텍스트·추론 강도·속도 설정을 따라가고 Maintainer 설정을 무시하던 문제를 수정했습니다.
- 긴 답이 한꺼번에 오면 잠시 흐리고 비어 보이던 문제를 수정했습니다.
- 멈춘 대기 입력이 복구 후 다시 실행되던 문제를 수정했습니다 (#142, thanks @22nsuk).
- 종료가 확인되지 않은 셸 작업이 끝난 것으로 처리되던 문제를 수정했습니다 (#133, thanks @22nsuk).
- 작업 공간 기록이 손상되면 실행 중인 작업의 보호가 풀리던 문제를 수정했습니다 (#117, thanks @22nsuk).
- Cursor 모델에서 도구 호출 ID가 바뀌고 멈춘 도구 넘김이 끝나지 않던 문제를 수정했습니다 (#156, thanks @22nsuk).
- 대화방에서 입력 중 표시가 끝나지 않거나, 말하는 도중 보낸 메시지가 빠지던 문제를 수정했습니다.
- 루틴 결과가 많이 쌓이면 봇 대화에 "결과 생략" 알림이 나오지 않던 문제를 수정했습니다.
- 봇 목록의 읽지 않음 숫자가 도구 호출까지 세어 부풀던 문제를 수정했습니다.
- 앱을 보고 있으면 다른 세션의 완료 알림까지 나오지 않던 문제를 수정했습니다.
- 휴대폰에서 세션 목록을 스크롤하는 중에 순서가 바뀌어 튀던 문제와, iPhone에서 설정 창이 바깥을 눌러도 닫히지 않던 문제를 수정했습니다.
- 답변의 메일 주소 링크를 눌러도 반응이 없던 문제를 수정했습니다.
